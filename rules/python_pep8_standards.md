# Règle de Qualité de Code : Standards Python & Typage Strict
- Tous les modèles de données doivent utiliser Pydantic v2 avec typage complet et ConfigDict strict.
- Respecter scrupuleusement la norme PEP 8 (indentation de 4 espaces, noms de fonctions en snake_case).
- Documenter les modules et fonctions avec des docstrings claires.
- Éviter le code mort ou les imports inutilisés.
